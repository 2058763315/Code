## 内容说明

### C语言
- **C基础**：变量与存储类别、分支结构、函数（含内联函数、函数指针）、作用范围等，含多份日期命名的课堂练习。
- **C进阶**：结构体（指针、数组、嵌套、类型定义）、联合、枚举、自定义数据类型、递归函数（阶乘、斐波那契）、按位操作、嵌套调用等。

### 数据结构（C++）
- **线性表**：动态数组（DynamicArray）、单向链表（LinkList）、双向链表（DoubleLinkList）、单向循环链表（CircleLinkList）、顺序栈（SeqStack）及其继承实现。
- **受限线性表**：顺序栈/队列与链式栈/队列（SeqStack、SeqQueue、LinkStack、LinkQueue）及对应作业。
- **树**：二叉树（BinaryTree）、二叉搜索树（BinarySearchTree）及练习。
- **二叉树**：二叉树与二叉搜索树的独立练习文件。

### 算法
- **算法概述**：代码复杂度分析。
- **算法策略**：递归（阶乘、斐波那契、青蛙跳台阶、汉诺塔）、贪心（钱币支付、西红柿首富）、分治（求位数、大数相乘）、动态规划（斐波那契、最小花费爬楼梯、最大子数组、回文判断、背包问题）。
- **排序**：冒泡、选择、插入、希尔、快速、归并、堆排序及练习。
- **查找**：顺序查找、二分查找（含无序数组二分练习）。

## 环境与编译

- C 语言代码使用 **C 语言编译器**（如 GCC / VS / Dev-C++）编译运行，文件后缀为 `.c`。
- 数据结构与算法代码使用 **C++ 编译器** 编译运行，文件后缀为 `.cpp`。

以 GCC 为例：

```bash
# 编译 C 语言代码
gcc 文件名.c -o 程序名

# 编译 C++ 代码
g++ 文件名.cpp -o 程序名
```
